# devbench-mod
Herdr layout + mod for a flat, agent-list-free sidebar.
- `layouts/devbench.base.json`: structure (shipped `main` minus agents panel, plus a garland block). `layouts/devbench.json` is generated by `node build.mjs` (base + `theme/christmas.layout.json` paint: gradients, pane borders).
- `mods/devbench-spaces`: clone of shipped `spaces`. Flat list (no worktree nesting), a tab-state glyph replaces the avatar, no branch/repo text, every tab holding an agent is listed flat under its space by tab name with its own state dot (click focuses). A tab is `done` only when ALL its agents are done.
- `mods/devbench-pane`: clone of shipped `pane` header: tinted by agent state, 3px left accent strip (state color, accent when focused), 16px logo. Layout also has a 2px focus border, radius 12, gap 10.
- `./install.sh [--dry-run]` copies both into `~/.config/herdr-app`; then `herdr-app do layout.switch '{"name":"devbench"}'`.
Derived from Herdr's shipped mod; re-clone to pick up upstream changes.

## Layers
- `core/`: pure state logic (tab state, rows, nav order). Tested: `node test/core.test.mjs`.
- `effects/`: motion helpers (smooth height/opacity, pulse, glyph-frame cycling). `FX.enabled=false` turns motion off.
- `theme/`: Christmas look: `christmas.json` (Herdr theme), `christmas.js` (glyphs, working snowflake frames, hat rule), `santa.svg` / `elf.svg`. Dispatcher gets the Santa hat, every other agent an elf hat.
- `mods/devbench-tree`, `mods/devbench-garland`: decoration blocks in the sidebar (tree with twinkling ornaments and a pulsing star; light string with snowflakes).
- Mods (`mods/*`) only compose the three. `install.sh` copies each layer's files next to the mods and `theme/*.json` into `themes/`.

## Pixel art
- Only the light bulbs and the Christmas tree are pixel art. The tree is an ASCII grid in `theme/sprites/tree.px`; `node build.mjs` renders it to a crisp SVG in `theme/generated/` and merges the layout paint. Tests: `node test/build.test.mjs`.
- Hats are small vector SVGs (`theme/santa.svg`, `theme/elf.svg`). Fonts, corners and gradients are the normal Herdr look.
- Markers are ASCII (`! * -`, and a `| / - \` spinner while working).
- `herdr-app shot <file.png>` captures the window; handy for checking the result.
