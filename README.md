# devbench-mod

A Christmas theme and a flat, agent-list-free sidebar for the Herdr app, built as a layout plus a few mods. Tokyo Night colours on black.

## What you get
- **Flat sidebar.** No agent list and no worktree nesting. Every tab that holds an agent is listed under its space by tab name, with the agent's logo in front and its state at the back. A tab is `done` only when **all** its agents are done. `agent.prev` / `agent.next` walk the tab rows; bind them in `keys.json` (I use `"alt-q"` and `"alt-w"`).
- **Decorated panes.** The header is tinted by agent state, with a rounded accent strip, a logo, a "Needs you" chip when blocked, and a string of lights on the focused pane.
- **Christmas decoration.**
  - A pixel-art light string across the top of the sidebar; each bulb blinks.
  - A pixel-art tree with twinkling ornaments.
  - Three pixel characters (Claude, Antigravity, Sol/Codex) that wander in front of the tree, rest for a random while, and now and then chat. They have a thin light outline so they stand out from the tree.
  - Falling snow over the tree.
  - The Herdr mark is a sheep pulling a sledge (the Herdr ram in costume).
  - Small Santa and elf hats on the agent logos: the dispatcher gets Santa, everyone else an elf.
- The tree scene is pure decoration. Only the sidebar rows and pane headers show real agent state.

## Install
```
./install.sh [--dry-run]
herdr-app do layout.switch '{"name":"devbench"}'
```
`install.sh` builds the sprites, copies the mods and each layer's files into `~/.config/herdr-app`, and installs the theme. Shipped Herdr layouts and mods are overwritten on start, so this repo works on **clones**; re-clone to pick up upstream changes.

## Layout of the repo
- `layouts/devbench.base.json`: structure (the shipped `main` minus the agents panel, plus a garland block). `layouts/devbench.json` is generated by `node build.mjs` (base + `theme/christmas.layout.json` paint).
- `mods/devbench-spaces`: clone of the shipped `spaces` mod (flat list, tab rows, state markers, nav order).
- `mods/devbench-pane`: clone of the shipped `pane` header mod.
- `mods/devbench-brand`: clone of the shipped `workspace-chrome` mod, with the sheep as the brand mark.
- `mods/devbench-garland`, `mods/devbench-tree`: the decoration blocks.

## Three layers
Mods only compose these; they never hold rules, motion or colours themselves.
- `core/`: pure logic, no UI. Tab state, rows, nav order, plus the crew's wandering and chatting and the snow, all driven by an injected random function so they can be tested.
- `effects/`: motion helpers (smooth and linear transitions, pulse, twinkle, drift, glyph-frame cycling). `FX.enabled = false` turns all motion off.
- `theme/`: the look. `christmas.json` (Herdr theme), `christmas.layout.json` (layout paint), `christmas.js` (glyphs, hats, crew and snow settings, speech lines) and the sprites.

## Pixel art
- Sprites are ASCII grids in `theme/sprites/*.px`: a `# scale N` line, palette lines `# K=#rrggbb ...`, then the grid (`.` is transparent). Optional `# upscale N` makes finer pixels, and `# outline #rrggbb T` adds a thin border.
- `node build.mjs` renders them to crisp SVGs in `theme/generated/` (plus `sprites.meta.js` with sizes and light positions) and merges the layout paint.
- Palette keys `1`-`4` are twinkling lights: drawn dim in the SVG, with a blinking overlay in the mod.
- Sprites: `tree.px`, `garland.px`, `char-claude.px`, `char-agy.px`, `char-codex.px`, `sheep.px`. Hats are small vector SVGs (`theme/santa.svg`, `theme/elf.svg`). Fonts, corners and gradients are the normal Herdr look.

## Tests and checking
- `node test/core.test.mjs`: logic (tab state, crew, snow). `node test/build.test.mjs`: the sprite parser, outline and lights.
- `herdr-app status` shows mod errors (empty means OK). `herdr-app shot <file.png>` captures the window. A layout change needs `layout.switch` away and back to reload.
